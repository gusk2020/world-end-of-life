# 第11次改修

## 画面
- 地図: 国の塗りつぶしなし・人口分布は既定で非表示。3つのAIの管轄を国境線の色(青・緑・橙)で示す。黒背景と走査線は維持。レーダー・ピクトグラム・層の切替は「詳細を見る」(`#mapmore`)に格納。
- 最初に見えるもの: 人類・資源・兆候(予測)・直近の重要な出来事・自分の方針(`#nowbox`)と、小さな3AI比較表(人口・資源・安定)。
- 上部に「いまの担当エリア／保存の世界」(`#whoami`)。色の選択画面に各色の保存の有無と年を表示。
- 最初の質問のあとの「進める／前のデータに戻る」を廃止。保存のある色を選ぶと、前の世界を別名(`.bak<時刻>`)で保存して読み戻せたときだけ新しい世界を始める(できなければ何も触らず選び直し)。
- 配分: プリセット(均衡/延命/安全/研究)で合計100%。微調整は他の項目へ比例配分して合計100%を保ち、変化を表示。未解放の項目は0のまま。「適用」するまで保存済みの配分は置き換わらない。

## 3AIの因果記録(`tri.cause`)
`原因 → 行動 → 結果` を、移住・援助・制裁・侵略・責任の移管・技術の先行・相互監査・拒否権・崩壊・持ち直しで記録。行動時点の人口・資源・ひずみを控え、6年後の実測値(予想が当たったか)を書き足す。重要度順に状況タブ・要点欄に出す。結果を作り話にしない(状態の差分のみ)。

## 均衡の体験
- 崩壊の原因を名指し(災害由来の負荷 `shock(..., src)`、過去の損失、予備の欠如、負荷の累積)。
- 持ち直し: ひずみが低く予備と資源があるとき、失った余力がピークの6割まで戻る(完全には戻らない)。
- しきい値の引き下げや乱数の連発はしていない。予備に配分した方針は同じ世界で崩壊が少ない(テストで確認: 70 ≤ 179)。
- 固定シード6つで2200年までの崩壊 34/11/32/16/21/30 回、持ち直し 5〜8 回(`tests/bench/eqexp.mjs`)。

## 性能
エンジンのノード計測(中央値, ms/年): 単一AI 0.95、3AI 1.03 → 0.80〜0.86。ブラウザ(CPU×4、2102→2302年、×1000): 第8次 1.3 秒、第9次相当 2.1〜2.3 秒、今回 2.1〜2.8 秒(誤差内でほぼ同等)。第8次との差は第9次で増えた計算によるもの。
実施: 物語の旗名の再計算を廃止(cityNarratives 95→24ms)、崩壊のときだけ国を抽出、オブジェクト形の固定。実機(Pixel 7a)の値ではない。
