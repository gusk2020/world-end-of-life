# 世界の終活者 (world-end-of-life) — 操作可能プロトタイプ

2020年1月1日から人類絶滅後の終幕まで通して遊べる、スマホ向けの軽量Webゲーム(ビルド不要・静的ファイルのみ)。
あなたは人類最後の管理AI。2100年まで世界を観察して成長し、以降は終活を管理する。人口には直接触れず、最後の一人まで幸福と尊厳を守り、人類消滅と同時に危険施設と機械文明を止めることが目標。

プレイURL: https://gusk2020.github.io/world-end-of-life/ (GitHub Pages)

## 遊び方
`index.html` を開く(GitHub Pages / 任意の静的サーバ)。ES Modulesを使うため `file://` ではなくHTTP経由で。
- 速度: ⏸ / ▶(1年/秒) / ⏩ / ⏭ / ⏭⏭(100年/秒)。重要な判断が来ると自動で止まる。
- 地図: 実在の国境(Natural Earth 110m)。国をタップで詳細。ピンチ/ドラッグ/＋－で拡大。レイヤ切替(人口/幸福/不安/施設)。
- 方針タブ: 2100年以降の資源配分(生存研究/終活支援/施設停止/機械停止準備/環境修復/文明遺産)、停止の進め方(合意/強制)、機械文明の方針、AIの学習方針。
- 記録タブ: セーブ3枠+自動セーブ、設定資料(科学と創作の区別)。

## 第1次改修の要点
- 黒背景の単色CRT端末風UI。青(初期)・緑・橙を右上で切替(設定はセーブと別に保存)。地図・文字・グラフ・砂時計は同じテーマ色。
- 人類とAIの砂時計を常時表示(上=生存/稼働、下=累計死亡/累計停止。砂は割合の概念表示、人数・個体数は数字で併記)。
- フィジカルAI(作品固有の設定): 核は固有のワンチップで複製不可、身体・周辺機器は交換・移設可能。新造は製造枠で制限。現実の技術で絶対的なコピー防止が証明されているわけではない。
- 世界遺産(実在)とゲーム独自候補を34件扱い、保護・記録保存・自然還元を選べる。
- 選択の即時/15年後の見込み、方針変更の10年後/40年後の差分、7指標のレーダー、最大のボトルネックと原因。
- 時代・地域・遺産・選択に連動する情勢描写、新イベント(都市の縮退、最後の学校、最後の祭り、遺産の見直し)、チュートリアル。

## 第2次改修の要点
- 砂時計を人類・AI・大型哺乳類の3つに。常時は小型、タップで拡大(累計・今年の増減・年次推移・種群別)。
- イベント本文は白字で、通常は3行に要約し、タップで全文。選択肢と数値は省略しない。
- 速度は「×1=現実1秒=ゲーム内1年」と明記し、選んだ速度は変更するまで維持(セーブ・イベント・再読込でも戻らない)。一時停止は別操作。
- 2100年以降の進行モード: 手動 / 半自動(国家・地域の縮退対応だけ自動) / 完全自動。2020〜2100年の選択から価値観(安全・人間の尊厳・自然環境・文明遺産・AI存続・野生動物)を数値化し、履歴が少ないときは既定の初期方針を併用。理由と結果をログと「自動判断」に残し、重要なものは未確認バッジで知らせる。
- 人口動態: 出生率は「希望」(絶滅の認識・静穏期・幸福・終活支援・資源・地域の遮蔽)で決まる。停滞や回復が条件付きで起こり、絶滅は約3100年前後(第1次は約2880年)。
- 天文現象(創作仮説)の強度が数百年かけて波打ちながら強まる。AIコアの早期故障が機械文明を弱らせ、遮蔽(研究)や製造枠の方針で結果が変わる。
- 大型哺乳類(成体約10kg以上、野生4群+家畜1群): 総個体数と生死の累計を管理。保護は人類の終活と資源・土地で競合し、絶滅は不可避でも、福祉・生息環境・生き延びる時間・生態系への影響が評価に残る。

## 第3次改修の要点(表示のみ。ゲームのロジックは変更なし)
- 砂時計を「粒が一つずつ動く」Canvas表現に刷新(`js/sand.js`)。輪郭と中央のくびれを明瞭にし、上=塗りつぶし(生存・稼働)、下=中空(累計の死亡・停止)で区別。
- 小型表示は省略表記(78.0億・1.2万など)と1粒の代表個体数。タップで画面の大部分に拡大し、人類・AI・大型哺乳類を切替。現在数・累計・今年の増減(正確な数値)と年次推移を表示。
- 死亡・停止は上から下へ粒が落ちて積もり、出生・新造は上部へ追加。粒の動きは表示専用でゲーム時間とは分離(遅い時は一粒ずつ、速い時は目で追える速度に自動調整、追いつかない分はまとめて更新)。
- 縮尺は自動(減るほど細かくなり最終段階で1粒=1個体)と固定(細かい/標準/粗い)を切替。縮尺と1粒の個体数を常に明示し、縮尺や速度で実際の数値は変わらない。
- 描く粒は最大1000粒/山。端末性能に応じて粒の大きさ・解像度・描画頻度を自動調整、背景タブでは停止し再表示時に最新へ同期。

## 第4次改修の要点(進行の流れのみ。シミュレーション結果は変わらない)
- イベント画面に「進行設定」を追加: 進行モード(手動/半自動/全自動)、観察時間(3/5/10秒、既定5秒)、観察方法(ゲーム時間停止/低速進行)。選択肢をタップで選び、「この設定で進行」で確定。設定は保存され、次のイベントでも保持。方針タブからも同じ設定を変更可能。
- 判断の確定後に「観察フェーズ」: 地図と3つの砂時計を見る時間。画面下に残り秒数・スキップ・直近の自動判断を表示。観察中は次のイベント画面を出さず、起きたイベントは保留して観察後に1件ずつ順番に処理(消失・重複・順序逆転なし)。
- 停止=観察中ゲーム時間を止める/低速=2秒で1年進める。ユーザーの速度設定は書き換えず、観察後はその速度へ戻る。手動の一時停止は常に優先(観察タイマーも止まる)。
- 半自動=地域縮小イベントのみ自動、全自動=2020〜2100年の方針傾向から全て自動(選択画面なし、理由は記録され後から確認可)。
- 再読込/ロード: 観察は破棄され一時停止で再開。保留中のイベントは残り、再開時に表示。
- UI状態(`js/flow.js`)とシミュレーション状態(`js/engine.js`)を分離。観察の有無・方式・時間・モードで結果(結末・人口・判断順)が一致することをテストで確認。

## 第5次改修の要点
- 施設の解体は国ごとの「実効力」で進む(電力・物流・技術者・機械の自動化)。発電を早く止める/物流が細る/保守要員が減ると遅れ、AIコア故障や国家間の不安(配分が削られる)も影響。解体は資源を使い、完了時に一部を回収。機械の増産は短期に資源を使う。事故率は変えていない(解体が間に合わず残った施設が老朽化して起きる)。
- 方針タブに「停止の順序」(危険度順/AI施設を先に/軍事を先に)。
- 状態連動イベント5種: 解体の停滞(主因を本文に表示)・最後の病院・孤立する人々・資源をめぐる対立・終活への反対運動。小規模イベントは8年以上空ける。
- 完全自動の配分は、施設が人類より長く残る危険に応じて停止配分を増やす。遺産の蓄積上限をわずかに拡張(遺産の守り手に到達可能に)。
- 資源の説明・配分名を修正(機械停止準備/施設停止・解体)。
- 難易度比較は `node tests/dist.mjs 3`(結末分布と主要指標)。到達結末は11→13種(再起動・止まらない工場・遺産の守り手が通常戦略で到達。早すぎた沈黙のみ未到達)。

## 第6次改修の要点
- **導入**: ゲーム開始時に世界観(7章・スキップ可・設定から再閲覧)。ワンチップAIの設定は作品固有の仮説と明記。
- **助走期間(2020〜2100)**: 方針・方針質問7種+既存の判断で価値観(安全・尊厳・自然・遺産・AI・野生動物)を形成。方針/遺産タブは2100年まで閉じ、状況タブで価値観を確認。2099年の最後の質問で手動/半自動/完全自動を選ぶ(既存の自動判断・価値観学習を再利用)。
- **メイン画面**: 世界地図の下にレーダーチャート(7指標)とピクトグラム盤を同時表示(360px)。
- **ピクトグラム** (`js/picto.js`): 原子力・化学・軍事・AI・宇宙・ダム・電力・資源・物流・解体・汚染・遺産・哺乳類・人口・不安・対立の16種。実際の内部状態から緑/黄/赤(丸/三角/八角形のバッジとラベル付き)。地図の国別マーカー(1国1つに集約・タップで詳細)、判断結果の指標差分。密度3段階(保存)。表示だけでシミュレーションには影響しない。
- **色別セーブ** (`js/saves.js`): 青・緑・橙に独立した世界を1つずつ(`weol.world.<色>`)。切替前に保存を検証、失敗時は切り替えない。空きの色は新規開始を案内。旧セーブは削除せず、空の色へ**コピー**のみ(上書きなし)。破損は消さず選択を尋ね、直前の保存から復元。
- **人類消滅後の地球** (`js/after.js`): 終幕後に観察(25年刻み・最大2万年)。自然/AI管理/後継存在/混合の4分岐は終幕時の状態(AI残存・方舟・観測者)から決定(乱数なし)。都市・植生・汚染・遺産・生物・機械・復興人類を年表と地図で表示。終幕の評価は不変。正常停止したAIは外部視点の記録として表示。
- テスト: `tests/run.mjs` に節18〜20、`tests/ui.mjs` に第6次の節。

## 構成
- `js/engine.js` シミュレーション本体(DOM非依存・シード固定・JSON保存可能)
- `js/data.js` 初期世界(42か国+6地域圏、6分類の施設を個別生成: 約1450基)
- `js/mapdata.js` 国境SVG(`tools/build_map.mjs` で生成)
- `js/sand.js` 砂時計の表示(粒・落下・縮尺・描画ループ。表示専用) / `js/life.js` 天文現象・大型哺乳類 / `js/heritage.js` 遺産 / `js/narrative.js` 情勢描写 / `js/insight.js` 指標・見込み・ボトルネック
- `js/ui.js` 画面 / `tests/` 自動完走・分岐・砂時計整合・セーブ互換テスト、`tests/ui.mjs` 画面テスト(360px・テーマ・タップ・セーブ)

## テスト
`node tests/run.mjs`(Node 18+、依存なし)。13種の戦略ボットが2020年→絶滅→終幕まで自動完走し、結末の分岐・再現性・セーブロード・全15結末の到達性を検証する。

画面テスト(任意): 静的サーバを起動し `PW=<playwright-core> node tests/ui.mjs`(Chromiumが必要)。
