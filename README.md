# 世界の終活者 (world-end-of-life) — 操作可能プロトタイプ

2020年1月1日から人類絶滅後の終幕まで通して遊べる、スマホ向けの軽量Webゲーム(ビルド不要・静的ファイルのみ)。
あなたは人類最後の管理AI。2100年まで世界を観察して成長し、以降は終活を管理する。人口には直接触れず、最後の一人まで幸福と尊厳を守り、人類消滅と同時に危険施設と機械文明を止めることが目標。

プレイURL: https://gusk2020.github.io/world-end-of-life/ (GitHub Pages)

## 遊び方
`index.html` を開く(GitHub Pages / 任意の静的サーバ)。ES Modulesを使うため `file://` ではなくHTTP経由で。
- 速度: ⏸ / ▶(1年/秒) / ⏩ / ⏭ / ⏭⏭(100年/秒)。重要な判断が来ると自動で止まる。
- 地図: 実在の国境(Natural Earth 110m)。国をタップで詳細。ピンチ/ドラッグ/＋－で拡大。レイヤ切替(人口/幸福/不安/施設)。
- 方針タブ: 2100年以降の資源配分(生存研究/終活支援/施設停止/機械停止準備/環境修復/文明遺産)、停止の進め方(合意/強制)、機械文明の方針、AIの学習方針。
- 記録タブ: セーブ3枠+自動セーブ、設定資料(科学と創作の区別)。

## 構成
- `js/engine.js` シミュレーション本体(DOM非依存・シード固定・JSON保存可能)
- `js/data.js` 初期世界(42か国+6地域圏、6分類の施設を個別生成: 約1450基)
- `js/mapdata.js` 国境SVG(`tools/build_map.mjs` で生成)
- `js/ui.js` 画面 / `tests/` 自動完走・分岐テスト

## テスト
`node tests/run.mjs`(Node 18+、依存なし)。13種の戦略ボットが2020年→絶滅→終幕まで自動完走し、結末の分岐・再現性・セーブロード・全15結末の到達性を検証する。
